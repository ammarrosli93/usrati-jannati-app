# Usrati Jannati

**Usrati Jannati** (Arabic for _"My Family, My Paradise"_) is a personal **family tree management application** built with **React + TypeScript**, designed to help users create, visualize, and manage family relationships.

The idea came from trying to track my own relatives, inspired by the Arab tradition of constructing family trees to keep records of family members. The app also aims to include an **inheritance calculator (Faraidh)** — inheritance plays an important role in Muslim life as one of the ways wealth is distributed among relatives after death, and Faraidh calculations can be complex. This feature is designed to help Muslims work through those calculations more easily.

This project is currently under development as part of my learning journey into **full-stack development, authentication, and scalable application design**.
